# Lift Log

A workout tracker for weight lifting. Create workouts, log sets, reps and weight, and see progress charts for every lift.

It's an installable web app (PWA). It runs offline, and your data is saved on your phone.

## Install on Android
1. Open the GitHub Pages address for this repo in Chrome.
2. Tap ⋮ → **Install app** (or **Add to home screen → Install**).

## Back up your data
Open Settings (⚙) → **Save backup file**. Restore it with **Restore from backup file**.
